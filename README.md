# John Andre — Virtual Assistant Portfolio

One-page portfolio site (plain HTML, CSS, JavaScript).

## Files
- `index.html` — page content
- `styles.css` — Clarity theme (teal + amber, Sora + Inter)
- `script.js` — drawers, animations, toolkit filter, contact selector
- `assets/john-profile.jpg` — profile photo (must stay inside the `assets` folder)

## Publish on GitHub Pages
Upload these files to the repo root, then Settings > Pages > Deploy from a branch > main > / (root).
