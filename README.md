# John Andre — Virtual Assistant Portfolio

A responsive one-page portfolio website for a freelance Virtual Assistant.

## Files
- `index.html` — page content
- `styles.css` — responsive design and animations
- `script.js` — mobile menu, reveal animations, current year
- `assets/john-profile.jpg` — profile photo

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email.
2. Replace the LinkedIn placeholder with your actual LinkedIn profile URL.
3. Review portfolio descriptions and remove/adjust anything that should remain confidential.
4. Optionally add screenshots or thumbnails for your portfolio projects.

## GitHub Pages
Upload the contents of this folder to a GitHub repository. In GitHub, go to **Settings → Pages**, choose **Deploy from a branch**, select the main branch and `/ (root)`, then save.
